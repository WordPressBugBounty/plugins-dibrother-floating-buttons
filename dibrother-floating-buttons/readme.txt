Thêm các nút liên hệ (Gọi, Zalo, Messenger) cố định vào website WordPress. Kết nối tức thì với khách hàng.

== Description ==

Bạn đang tìm kiếm một plugin thêm nút liên hệ hiệu quả cho website WordPress? Nút Bấm Liên Hệ Dibrother là giải pháp tối ưu giúp bạn kết nối tức thì với khách hàng qua các nút gọi điện, Zalo, Messenger cố định và chuyên nghiệp. Cài đặt chỉ trong vài phút, tùy chỉnh màu sắc, vị trí dễ dàng mà không cần biết code. Tăng tỷ lệ chuyển đổi và nâng cao trải nghiệm người dùng ngay hôm nay!

TÍNH NĂNG CHÍNH:

Đa Kênh Liên Lạc: Tích hợp sẵn các nút phổ biến nhất: Gọi điện, Zalo, Facebook Messenger.

Nút Lên Đầu Trang: Cải thiện trải nghiệm người dùng trên các trang dài.

Tùy Chỉnh Dễ Dàng: Thay đổi màu sắc, vị trí (trái/phải) và bật/tắt hiệu ứng sóng thu hút.

Hoàn Toàn Đáp Ứng: Hiển thị đẹp mắt trên mọi thiết bị từ máy tính đến điện thoại di động.

Nhẹ & Tối Ưu: Mã nguồn sạch, không làm chậm website của bạn.

Chuẩn SEO: Các liên kết ngoài được tự động thêm rel="nofollow".

== Installation ==

Tải file .zip của plugin về máy tính.

Trong trang quản trị WordPress, vào Plugins > Add New.

Nhấp vào Upload Plugin và chọn file .zip bạn vừa tải.

Nhấp Install Now và sau đó Activate Plugin.

Đi tới Settings > Nút Bấm Liên Hệ Dibrother để bắt đầu cấu hình.

== Frequently Asked Questions ==

= Làm thế nào để thay đổi màu sắc của các nút? =

Trong trang cài đặt của plugin, mỗi nút sẽ có một tùy chọn bảng màu. Bạn chỉ cần nhấp vào và chọn màu mình mong muốn.

= Plugin có hoạt động trên điện thoại không? =

Có, plugin được thiết kế để hoạt động và hiển thị hoàn hảo trên mọi thiết bị di động và máy tính bảng.

= Plugin có làm chậm website của tôi không? =

Không. Plugin được viết với mã nguồn rất nhẹ và được tối ưu hóa để đảm bảo không ảnh hưởng đến tốc độ tải trang.
